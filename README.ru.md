# GeTools

**Gemini как локальный AI-агент на вашем рабочем столе**

*Тонкая Electron-оболочка, которая превращает Gemini в настоящего исполнителя задач — с доступом к терминалу, файловыми операциями, снапшотами и системой плагинов.*

## Что это такое?

GeTools оборачивает [Gemini](https://gemini.google.com) в десктопное приложение и инжектирует в страницу кастомный агентный слой. В результате Gemini может выполнять команды в терминале, читать и записывать файлы, делать снапшоты проекта и расширяться плагинами — не выходя из интерфейса чата.

Модель остаётся той же. Интерфейс остаётся тем же. GeTools просто добавляет связь между ответами Gemini и вашей локальной машиной.

---

## Как это работает

```
Вы пишете сообщение
    ↓
GeTools добавляет маркер агента + опциональный блок UltraThink
    ↓
Gemini отвечает с [EXECUTE: команда] или [CREATE_FILE: {...}]
    ↓
GeTools перехватывает ответ, показывает карточку подтверждения
    ↓
Вы разрешаете → команда выполняется → результат скрыто передаётся Gemini
    ↓
Gemini продолжает задачу
```

Весь цикл происходит внутри окна чата. Системные сообщения (`[SYSTEM]`) скрыты от пользователя — Gemini видит их как контекст, вы видите чистый разговор.

## Возможности

### 🖥️ Выполнение команд в терминале
Gemini может запускать shell-команды на вашей Windows-машине. Каждая команда показывает карточку подтверждения перед выполнением. Вы всегда можете отклонить.

### 📁 Файловые операции
Создавайте и записывайте файлы прямо из чата через `[CREATE_FILE: ...]`. Никакого копирования вручную.

### 🧠 Режим UltraThink
Заставляет Gemini рассуждать перед действием. Когда включён, каждый ответ начинается со структурированного блока анализа (`# Анализ`) перед любой командой или ответом. Рассуждения сворачиваются в виджет «Раздумия» — видимый, но не мешающий.

### 📸 Снапшоты
Сделайте контрольную точку файлов проекта перед рискованной операцией. Восстановите одним кликом если что-то пошло не так. Снапшоты хранятся локально в `userData/snapshots/`.

### 🔌 Система плагинов
Расширяйте GeTools кастомными командами. Плагин — это манифест `plugin.json` + JS-файл, который вызывает `window.getools.registerCommand(name, handler)`. Устанавливается из папки или ZIP-архива.

**Пример плагина** (`example-plugin/`):
```js
window.getools.registerCommand('READ_URL', async (url) => {
  const res = await fetch(url)
  const text = await res.text()
  return { success: true, stdout: text.slice(0, 8000) }
})
```
После этого Gemini может использовать `[READ_URL: https://example.com]` для получения содержимого веб-страниц.

### 🌐 Поддержка языков
Выберите русский или английский при первом запуске. Язык влияет на UI, инструкции агента и язык ответов Gemini (заголовок `Accept-Language`).

## Быстрый старт

**Требования:** Node.js 18+, Windows

```bash
# Клонировать и установить зависимости
git clone https://github.com/your-username/getools.git
cd getools
npm install

# Запустить
npm start

# Собрать установщик
npm run build
```

При первом запуске GeTools предложит выбрать язык. После этого загружается Gemini и агент инжектируется автоматически.

## Структура проекта

```
getools/
├── main.js          — Главный процесс Electron, IPC-обработчики, CDP-инъекция
├── inject.js        — Агентский скрипт, инжектируемый в страницу Gemini

├── splash.html      — Экран загрузки + выбор языка

├── example-plugin/  — Пример плагина: команда READ_URL
│   ├── plugin.json
│   └── plugin.js
└── package.json
```

## Написание плагина

Плагин состоит из двух файлов:

**`plugin.json`**
```json
{
  "id": "my-plugin",
  "name": "Мой плагин",
  "version": "1.0.0",
  "description": "Что делает плагин",
  "icon": "extension",
  "commands": ["MY_COMMAND"],
  "inject": "plugin.js",
  "prompt": "Необязательная инструкция для Gemini о том, когда использовать [MY_COMMAND: ...]"
}
```

**`plugin.js`**
```js
window.getools.registerCommand('MY_COMMAND', async (payload) => {
  // что-то делаем с payload
  return { success: true, stdout: 'результат' }
}, {
  label: 'Моя команда',
  icon: 'extension',
  description: 'Что делает эта команда'
})
```

Установите, открыв панель плагинов (через тулбар или меню ⋮ → Плагины GeTools) и перетащив папку или ZIP-архив.

Если плагин содержит поле `prompt`, GeTools автоматически добавит его в сохранённые инструкции Gemini — чтобы модель знала, когда и как использовать новую команду.

## Модель безопасности

- Каждая команда `[EXECUTE: ...]` требует явного подтверждения пользователя перед выполнением
- Команды выполняются в настроенной рабочей директории (`userData/settings.json → cwd`)
- Запись файлов за пределами рабочей директории логируется с предупреждением
- Агент активируется только когда сообщение содержит маркер `GETOOLS activates`
- Без маркера Gemini ведёт себя как обычный ассистент — никаких команд, никаких системных сообщений

---

## Архитектурные заметки

GeTools использует Chrome DevTools Protocol (CDP) Electron для инжекции `inject.js` в страницу Gemini после её загрузки. Это не требует модификации кода Gemini и работает независимо от обновлений страницы.

Системный промпт (`AGENT_PROMPT.md`) передаётся как `window.__geminiAgentPrompt` и добавляется в «Сохранённую информацию» Gemini (персональный контекст) при первом запуске. Это делает инструкции постоянными между сессиями без повторной инъекции.
